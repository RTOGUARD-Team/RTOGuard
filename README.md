# RTOGuard AI
 
AI-powered checkout risk scoring for Cash-on-Delivery (COD) orders. Every COD order is like an unsecured loan, so RTOGuard scores each one for return-to-origin (RTO) risk before it ships.
For each order it recommends one action: ship as normal, ask for a partial prepaid deposit, or route to a confirmation call.
A simulation shows the rupees saved per 1,000 orders, before vs after the AI (synthetic data, OpsGenieAI hackathon).
